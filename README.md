# Repo Vault

Every AI repo and Claude skill reviewed on [@ishaan.clearlyy](https://www.instagram.com/ishaan.clearlyy/), with a verdict.

I install the repos blowing up on GitHub, so you know what works, what's hype and what's a trap. If you came here from a DM, find your keyword in the table.

| Verdict | Meaning |
|---|---|
| ✅ **Clearly yes** | I ran it, and it does what it says. |
| 🤔 **Clearly hype** | It runs, but it doesn't live up to the stars. |
| ⛔ **Clearly not** | Warning signs, or it didn't work. Not linked on purpose. |
| ⚪ **Untested** | I covered it but haven't run it myself yet. |
